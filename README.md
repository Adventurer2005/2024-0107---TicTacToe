When downloading to play on a calculator, make sure to compile the code using an online or local compiler to an actual .8xp file,
since the text on the source file is just source text.  I used an online de-compiler to get the text for the source code:

https://www.cemetech.net/sc/

Now, when loading this into a calculator, usually one would use a silver USB to mini-jack cord.  
After downloading the program, everything is installed except for one variable: the matrix `[C]` variable.
You would need to initialize that before starting the program, first clicking on `2nd`, then `MATRIX` or `x^-1`, 
then move to the `EDIT` page on the top right by shifting right twice, and then scroll down to `3:` or click `3` to edit matrix `[C]`.
Now, to allocate the space necessary for the program, enter `3` both times for the length and height of the matrix.
To see a visual of what this should look like, view the `Setup` pictures I'm posting on this repository.
